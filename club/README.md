# COLACTIVE — מועדון פרטי

אתר למועדון פרטי של צעירים בתל אביב: שופוני, תל אביב ואלכוהול.

Next.js (App Router) + TypeScript + Tailwind, Supabase לשמירת הנתונים.
זו אפליקציה נפרדת משאר המאגר — כל הפקודות רצות מתוך התיקייה `club/`.

## איך זה עובד

1. **סיסמה** (`/gate`) — כל כתובת באתר מפנה לכאן עד שמזינים את `SITE_PASSWORD`.
2. **הרשמה** (`/join`) — אחרי הסיסמה: שם, טלפון, מייל, גיל (18+), אינסטגרם ואישור חוקי המועדון. רק אחרי ההרשמה
   האתר נפתח. ההרשמה נשמרת בעוגייה חתומה ל-90 יום.
3. **האתר**:
   - `/` — דף בית, עם באנר כשיש רשימה פתוחה.
   - `/list` — **הרשימה**: עד 40 מקומות, פתוחה לזמן מוגבל עם ספירה לאחור. כשהזמן נגמר או כשהמקומות נגמרים
     הדף ננעל. מי שנרשם/ה רואה שהוא/היא ברשימה גם אחרי הנעילה.
   - `/gallery` — גלריית תמונות עם תצוגה מוגדלת.
   - `/about` — המותג וחוקי הבית.
4. **ניהול** (`/admin`, סיסמה `ADMIN_PASSWORD`) — פתיחת רשימה חדשה (שם, מתי, פרטים, כמה דקות פתוחה, כמה
   מקומות), נעילה ידנית, מי ברשימה, וכל החברים הרשומים.

ההגבלה ל-40 נאכפת בבסיס הנתונים בפונקציה אחת שנועלת את שורת הרשימה (`club_join_list`), כך ששני אנשים שנרשמים
באותה שנייה לא יכולים לעבור את המכסה.

## הרצה מקומית

```bash
cd club
npm install
npm run dev
```

בפיתוח אין צורך בהגדרות: הסיסמה היא `club`, סיסמת הניהול `admin`, והנתונים נשמרים ב-`.data/club.json`.

## העלאה לאוויר

1. ב-[Supabase](https://supabase.com) — פרויקט חדש, ואז ב-SQL Editor להריץ את `supabase/schema.sql`.
2. ב-Vercel — פרויקט חדש מהמאגר עם **Root Directory = `club`**, ולהגדיר את המשתנים מ-`.env.example`
   (`SITE_PASSWORD`, `ADMIN_PASSWORD`, `SESSION_SECRET`, `SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY`).
   בפרודקשן האתר לא יעלה בלי שלושת הראשונים.

## עריכת תוכן

- **טקסטים ושם המותג** — הכל ב-`lib/brand.ts`.
- **תמונות לגלריה** — לשים קבצים (jpg/png/webp) ב-`public/gallery/`. הסדר הוא לפי שם הקובץ (`01.jpg`, `02.jpg`...),
  וארבע הראשונות מופיעות גם בדף הבית. התמונות שבתיקייה עכשיו הן placeholder — למחוק ולהחליף.
  שימו לב: קבצי התמונות עצמם לא מוגנים בסיסמה (מי שיודע את הכתובת המדויקת של קובץ יכול לפתוח אותו), אז לא
  להעלות לשם תמונות שאסור שידלפו.
